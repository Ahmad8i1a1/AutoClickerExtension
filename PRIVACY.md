# Privacy Policy for Auto Clicker & Swipe Automation

**Last updated:** September 25, 2026

## 1. Introduction
Auto Clicker & Swipe Automation ("we", "our", or "the extension") values your privacy. This Privacy Policy outlines our data handling practices for the Auto Clicker & Swipe Automation Chrome extension.

## 2. Information Collection and Use
- **No Personal Data Collection:** The extension does not collect, record, track, or transmit any personally identifiable information (PII), such as names, email addresses, passwords, IP addresses, or browsing history.
- **Local Settings & Coordinates:** All settings, coordinates, point definitions, and configuration presets that you configure are stored strictly locally on your computer via the Chrome Storage API (`chrome.storage.local`).
- **No Third-Party Transmission:** No data is ever transmitted to external servers, cloud services, analytics providers, or third parties.

## 3. Extension Permissions
The extension requests only the minimum permissions necessary for its intended functionality:
- `storage`: Saves your action points, delays, and preferences locally.
- `activeTab`: Interacts with the active webpage to capture click coordinates and perform automated actions.
- `scripting`: Renders the visual point picker and dispatches click/swipe events on the target webpage.
- `tabs`: Allows the extension to check tab status and trigger page reloads when the auto-refresh feature is enabled.
- `alarms`: Schedules periodic auto-refresh intervals.
- `<all_urls>`: Enables you to use the automation on any website of your choosing.

## 4. Changes to This Privacy Policy
We may update this Privacy Policy from time to time. Any changes will be posted directly to this repository.

## 5. Contact
If you have any questions or feedback regarding this Privacy Policy, please open an issue on our GitHub repository.
